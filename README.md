# Static Website Hosting with GitHub Pages

## Overview
A simple static website built using HTML and CSS and hosted with GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub Pages

## Features
- Simple and responsive website
- Version control with Git
- Free static website hosting using GitHub Pages

## Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.

## Deployment
The website can be deployed through the repository's GitHub Pages settings.
